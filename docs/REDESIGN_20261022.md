# UKOM Health Pro: public website redesign

Existing site: https://andazmortin88.github.io/tryoutnew/
Baseline: d09c0cb4d10d726a5c934a69acb90a474d46cf13

## Delivered

- Distinct navy, blue and white public identity with consistent type, spacing and restrained borders.
- Program discovery for Ners, D3 Keperawatan, Bidan and Profesi Apoteker.
- Interactive study preview, retained public editorial question examples, study tips, live aggregate registration statistics, FAQ and service links.
- Pricing sourced from the existing application configuration; no independent checkout added.
- Immediate landing render without the former opening overlay, moving ticker, decorative orb or timed promotional popup.
- Responsive layouts, mobile navigation, reduced-motion support, keyboard focus and skip navigation.
- Existing Google verification, canonical URL, SEO pages, sitemap and social links preserved.

## Verification

- Production build passed with locked dependencies (`npm ci`, `npm run build`).
- Browser checked: desktop, 390 px and 320 px iframe viewports; program switching, editorial preview switching, rationale expansion, FAQ, mobile navigation and anchor destinations.
- Narrow-header spacing corrected after browser inspection. No desktop overflow or missing anchor destinations; logos loaded.
- All file references in the deployed root landing and public SEO pages resolve.
- Byte comparison against baseline: the complete App function, all components from Onboarding through the end of the module, RegistrationStats and LandingQuestionPreview remain identical.
- Production Content Security Policy is identical. Supabase SQL/functions and dependencies are unchanged.
- New landing code introduces no raw HTML injection, executable string evaluation, privileged credentials, third-party scripts, API requests or authorization decisions. Program selection retains the existing preference key and Google login callback.
- Local HTTP preview required omitting `upgrade-insecure-requests` from the untracked preview HTML only. This change is absent from source and production output.

## Limits

This is a public UI redesign and targeted regression/security review, not an exhaustive security audit. No signed-in account, paid exam or live financial transaction was exercised. Production RLS, webhook behavior and access isolation were not independently re-audited. Responsive tests use browser frames rather than physical devices. Authenticated dashboard, exam UI and legal/SEO article templates retain their existing layouts.

## Rollback

Revert the redesign merge/commit and allow GitHub Pages to redeploy. No database rollback is required.
